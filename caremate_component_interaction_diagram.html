Scope: This diagram is based on the project component list and functionality description provided for CareMate. It labels interaction types such as Wi-Fi, Bluetooth, USB/COM serial, GPIO/PWM/sensor wiring, HDMI, API calls and power.

5. Simple Architecture Statement for Report

CareMate uses a two-computer and microcontroller architecture. The Raspberry Pi 4B is the robot brain for Python logic, camera input, AWS AI services and movement decisions. The Windows Surface Book 2 acts as a media and electronics bridge, playing family videos/photos on the TV and exchanging serial commands with the Raspberry Pi Pico 2WH. The Pico handles low-level electronics such as LED strip control and safety sensors. AWS Rekognition, Polly and Lex V2 provide emotion detection, natural speech and conversational intent understanding.
